• Run mysql from cmd: 
    1. Search "mysql" and find mysql command line client
    2. a. cd C:/"Program Files"/MySQL/"MySQL Server 8.0"/bin 
       b. run ./mysql -u root -p
    3. a. Add to env path C:\Program Files\MySQL\MySQL Server 8.0\bin 
       b. Restart prompt 
       c. run mysql -u root -p
• Exit mysql from cmd: run exit;
